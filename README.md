# SQL & Data Science Portfolio

A collection of SQL queries, data pipelines, and analytical projects. This repo is used to document my problem-solving process, write clean and modular code, and explore different datasets.

## 📂 Repository Structure
- `sql/`: Advanced SQL queries (CTEs, window functions, aggregations) for business metrics and data transformation.
- `notebooks/`: Python-based EDA and machine learning models.
- `data/`: Sample datasets and data dictionaries (large files are excluded via `.gitignore`).
- `src/`: Reusable Python scripts for data pipelines.

## 🛠️ Tech Stack
- **Data Extraction:** SQL (PostgreSQL / BigQuery), advanced CTEs, window functions, query optimization
- **Analysis & Modeling:** Python (Pandas, NumPy, Scikit-learn, Matplotlib/Seaborn)
- **Visualization & Reporting:** Power BI (DAX, data modeling), Excel (Power Query, Pivot Tables, advanced formulas)
- **Tools & Workflow:** Git, GitHub, Jupyter Notebooks, VS Code

## 📊 Current Projects
- **Cohort Retention Analysis (template.sql`)**: Calculates month-over-month retention rates for new customer cohorts, handling nulls and filtering incomplete orders to feed into a BI dashboard.
